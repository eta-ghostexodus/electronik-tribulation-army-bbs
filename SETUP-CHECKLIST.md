# ETA BBS GitHub Deployment Checklist

- [ ] Create a public GitHub repository.
- [ ] Confirm Issues are enabled.
- [ ] Upload every project file, including `.github`.
- [ ] Set Settings → Pages → Source to **GitHub Actions**.
- [ ] Run Actions → **Bootstrap ETA BBS**.
- [ ] Confirm Actions → **Deploy ETA BBS** succeeds.
- [ ] Open the published `github.io` address.
- [ ] Create a test forum thread from the BBS.
- [ ] Post a test comment in the shared chat Issue.
- [ ] Play a door game and submit a test score.
- [ ] Add `score:verified` to the test score if desired.
- [ ] Edit `config.js` for permanent branding changes.
